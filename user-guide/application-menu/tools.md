# Tools Menu

The **Tools** section of the [application menu](slug://app-menu-section) provides quick access to several traffic-related utilities:

- **Advanced Replay**&mdash;Opens the **Advanced Replay** configuration prompt for one or more selected sessions, letting you control the number of repeats and whether they run sequentially or in parallel. You can also invoke it from the **Live Traffic** context menu or with the **Alt+R** (**Option+R** on macOS) shortcut. See [Advanced Replay](slug://replaying-traffic#advanced-replay) for full details.
- **Decode Value**&mdash;Opens the same decode utility available from the session inspectors' context menu, letting you decode Base64, EscapedSequences, Encoded URL, Hex, or Encoded HTML values. See [Context Menu](slug://inspector-types#context-menu) for the list of supported decode formats.
- **AutoSave**&mdash;Opens the **AutoSave** dialog, which lets you automatically and periodically export captured HTTPS data to a snapshot file. You can also invoke it with the **Alt+S** (**Option+S** on macOS) shortcut, and toggle it on or off with **Ctrl+Alt+S** (**Cmd+Option+S** on macOS). See [Automated Save and Export](slug://fiddler-saving#automated-save-and-export) for full details.
- **Host Remapping**&mdash;Opens the **Host Remapping** window, which lets you redirect traffic for a host to a different host, IP address, or port. You can also invoke it from the status bar's route icon indicator, or with the **Alt+H** (**Option+H** on macOS) shortcut. See [Host Remapping](slug://host-remapping) for full details.
