# Application Menu

The Fiddler application menu is located at the top-left corner of Fiddler Everywhere. It is organized into the following sections:

- [**View**](slug://app-menu-view)&mdash;Options to customize the application's UI, such as zoom level and tab navigation.
- [**Tools**](slug://app-menu-tools)&mdash;Quick access to traffic-related utilities, such as Advanced Replay, Decode Value, AutoSave, and Host Remapping.
- [**Certificate**](slug://app-menu-certificate)&mdash;Options to install, export, reset, or remove the Fiddler root certificate, and to control HTTPS traffic capturing.
- [**Help**](slug://app-menu-help)&mdash;Support resources, release notes, application logs, and about information.

On macOS, the application also contains specific OS menus called **Fiddler Everywhere** and **Edit**, described below.

## Fiddler Everywhere (macOS only)

This menu is available only on the macOS version of Fiddler Everywhere. It contains the following options:

- **About**&mdash;Opens an application dialog with detailed information about the currently installed version of Fiddler Everywhere.
- **Settings**&mdash;A fast link to the Fiddler Everywhere **Settings** menu.
- **Hide Fiddler Everywhere**
- **Hide Others**
- **Show All**
- **Quit Fiddler Everywhere**

## Edit (macOS only)

This menu is available only on the macOS version of Fiddler Everywhere. It contains the following options for generic UI interaction:

- **Undo**
- **Redo**
- **Cut**
- **Copy**
- **Paste**
- **Select All**
